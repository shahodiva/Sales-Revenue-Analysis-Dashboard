# 📊 Sales & Revenue Analysis Dashboard

## 1. Project Overview

The Sales & Revenue Analysis Dashboard is an interactive business intelligence application developed using Python, Pandas, Plotly and Streamlit.

The project analyzes sales transactions and provides interactive insights into revenue, profit, products, customers, regions and payment methods.

The dashboard allows users to filter the data and dynamically analyze business performance.

---

## 2. Project Objectives

The main objectives of this project are:

- Analyze sales and revenue performance.
- Track important business KPIs.
- Identify top-performing products.
- Identify high-value customers.
- Analyze regional sales performance.
- Analyze category-wise sales and profit.
- Analyze payment methods.
- Identify monthly sales trends.
- Calculate profit margins.
- Generate automatic business insights.
- Provide an interactive dashboard.

## 4. Dataset

The project contains 5,000 sales transaction records.

The dataset contains 16 original columns:

- Order_ID
- Order_Date
- Customer_ID
- Customer_Name
- Product_ID
- Product_Name
- Category
- Region
- State
- Quantity
- Unit_Price
- Discount
- Sales
- Cost
- Profit
- Payment_Method

After data preprocessing, additional analytical columns were created:

- Year
- Month
- Month_Name
- Quarter
- Profit_Margin
